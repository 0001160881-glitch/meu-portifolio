ChocoDelícia: Demonstração de Página Web

*Tecnologias:* HTML5, CSS3 (Layout, Estrutura Semântica, Imagem e Listas)

Este projeto apresenta uma página web de vitrine de produto criada em HTML5 e CSS3 puro. O objetivo é demonstrar a construção de uma estrutura completa e estilizada com cabeçalho, menu de navegação, seção principal de produto com imagem e descrição detalhada, e um rodapé informativo. O destaque da página é o Chocolate MegaCroC, exibindo informações como composição, preço e botão de compra, simulando um site comercial simples e funcional.

Cursos de Desenvolvimento de Software: Demonstração de Página Web

Este projeto apresenta uma página institucional de cursos desenvolvida com HTML5 e CSS3, simulando um site de escola de tecnologia. O layout destaca o cabeçalho com título e link de navegação, uma imagem ilustrativa de programação e uma seção principal listando ofertas de cursos como Front-end, Back-end e Ciência de Dados. Também inclui um formulário de inscrição para newsletter e um rodapé com direitos autorais e links de privacidade. O objetivo é demonstrar boas práticas de estruturação semântica e design limpo para páginas informativas.
